# Contributing to Stock-Market

1. Read the README and architecture guide.
2. Create a focused branch instead of committing to `main`.
3. Install the project's dependencies using the README instructions.
4. Run the checks listed in [docs/TESTING.md](docs/TESTING.md).
5. Submit a pull request describing the problem, solution, verification evidence and unresolved risks.

### Code quality

Keep fixes small and explain trade-offs. Do not claim features exist without source code or tests. Update documentation when changes affect setup or behavior. Never commit credentials, private data, generated databases or sensitive test fixtures.

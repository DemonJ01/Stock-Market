# Security policy — Stock-Market

## Scope

Predictions are experimental, not investment advice. No walk-forward evaluation, reproducible random seeds, live-trading support, execution engine, or production monitoring. Yahoo Finance data can change or become temporarily inaccessible. The comparison chart shows raw prices, not comparable normalized performance.

The project is not certified for production use and does not promise a formal security response SLA.

## Reporting concerns

Avoid posting credentials, personal information or exploit details in a public issue. Contact a maintainer through a verified private channel or GitHub private vulnerability reporting if it is enabled.

## Contribution safeguards

- Use environment variables and secret managers, never hardcoded real credentials.
- Do not commit customer, patient, user or personal datasets.
- Review authentication, authorization, external APIs and dependency updates before release.
- Do not equate successful syntax checks with penetration testing.
